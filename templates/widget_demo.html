🚀 One-Line Integration

Add this single line of code to your website:

<script src="https://your-domain.com/widget.js"></script>

That's it! The widget will appear in the bottom-right corner of your page.

📍 API Endpoint

Send messages to our API:

POST https://your-domain.com/api/chat
Content-Type: application/json

{
  "message": "Your question here",
  "api_key": "optional-api-key"
}

✨ Customization

Before the widget script, add your config:

<script>
  window.ConvinConfig = {
    apiUrl: 'https://your-domain.com/api/chat',
    title: '💬 Support',
    position: 'bottom-right'
  };
</script>
